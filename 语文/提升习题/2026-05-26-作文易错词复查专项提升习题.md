# 作文易错词复查专项提升习题

关联分析：[[2026-05-26-Leo作文能力评估与提升方案]]
训练目标：建立 Leo 作文常见易错词清单，写完作文后能主动复查。
建议用时：10 分钟

## Leo 易错词清单

先读 2 遍，再遮住右边写一遍。

| 易错写法 | 正确写法 |
| --- | --- |
| 小数 | 小树 |
| 以经 | 已经 |
| 幸遇 | 幸福 |
| 觉的 | 觉得 |
| 开使 | 开始 |
| 天作 | 工作 |
| 一变 | 一遍 |
| 如 | 如果 |
| 牵成掏 | 牵好 |
| 尊敬与感激 | 尊敬和感谢 |

## 第一组：改错

把下面词语改正确。

1. 我以经写完作业了。____
2. 我觉的这本书很有意思。____
3. 小树给人带来幸遇生活。____
4. 食堂阿姨开使了一天的天作。____
5. 她把桌子擦了一变。____

## 第二组：放进句子里

用下面 4 个词各写一句话：

1. 已经：____
2. 觉得：____
3. 幸福：____
4. 开始：____

## 自查标准

- 5 个改错至少改对 4 个。
- 自己写的句子中不能再出现错写词。
