# Leo 学习项目使用手册

## 1. 启动系统

进入网站目录：

```bash
cd /Users/ben/Desktop/leo-notebook/网站
```

首次使用或依赖变更后：

```bash
npm install
```

初始化或升级数据库：

```bash
node scripts/init-db.mjs
```

启动网站：

```bash
npm run dev -- --port 5173
```

终端会显示实际访问地址。如果 5173 已占用，会自动使用其他端口。

## 2. 日常学习流程

### 家长端

1. 在“素材中心”选择“新增素材”。
2. 选择科目、素材类型、日期、教材信息和图片或 PDF。
3. 保存后打开素材复核页面。
4. 启动智能分析。
5. 对结构化题目和诊断结论逐项校对。
6. 将正确结论标记为“确认”，不确定内容标记为“需复核原卷”。
7. 选择“确认并写入知识画像”。
8. 在“训练与复习”生成第一轮训练。
9. 查看自动质量检查结果，必要时编辑、删除、锁定或重新生成题目。
10. 质量检查通过后发布给 Leo。
11. 第一轮完成后，根据错题生成第二轮强化。
12. 在“学习报告”查看改善、持续问题和下一步建议。

### Leo 端

1. 切换到“Leo 端”。
2. 在“今日学习”中打开家长已发布的任务。
3. 完成题目并提交。
4. 在“错题讲解”查看需要继续理解的知识标签。
5. 在“到期复习”完成系统安排的间隔复习。
6. 在“我的进步”查看掌握度变化。

草稿训练不会出现在 Leo 端。

## 3. 素材录入规则

- 一次最多上传 6 个图片或 PDF。
- 图片和 PDF 原件会保存到对应学科的 `原始素材/`。
- PDF 会生成分页分析图。
- 模糊、方向错误或识别置信度低的内容应先复核原卷。
- 不覆盖学生原作、原图和人工校对稿。
- 作文原文、修改建议和优化稿必须分开保存。

## 4. 训练题管理

- 第一轮用于判断 Leo 是否理解知识点。
- 第二轮必须读取第一轮错题和错因，不是简单换数字。
- “锁定”题目会在重新生成时保留。
- 选择题必须有 4 个有效选项。
- 题目缺少答案、讲解或出题依据时不能发布。
- 质量检查不通过时，先修改或重新生成，不要强行发布。

## 5. 智能配置

### 技能

- 点击技能卡片查看当前生效内容和历史版本。
- 修改后先保存草稿。
- 确认无误后发布新版本。
- 需要时可以回退到历史版本。

### 提示词

- 每次修改都创建新版本。
- 变更说明应写清解决了什么问题。
- 发布前建议使用同一份真实素材比较新旧结果。

### 模型与任务路由

- 模型页面显示密钥是否已配置，不显示密钥内容。
- 任务路由决定每类任务使用的技能、提示词和模型。
- 模型失败信息可在“运行记录”查看。

## 6. 数据维护

在“智能配置 -> 数据维护”中：

- “开始检查”用于发现缺失原始文件和孤立数据。
- “下载 JSON 备份”用于导出全部动态业务数据和配置版本。
- 检查只读，不会自动删除或修复资料。

## 8. 常见问题

### Leo 端没有任务

检查对应训练计划是否：

1. 已生成题目。
2. 已通过质量检查。
3. 已选择“发布给 Leo”。

### 素材页面没有原图

到“智能配置 -> 数据维护”运行一致性检查，确认数据库记录的文件路径实际存在。

### 智能分析失败

检查：

1. 模型密钥是否已配置。
2. 任务路由是否启用。
3. 对应技能、提示词和模型是否存在。
4. “运行记录”中的错误说明。

### 要升级项目技能

优先通过“智能配置 -> 技能”维护。项目真实技能源仍位于：

```text
技能/student-homework-diagnosis/
技能/chinese-reading-diagnosis/
技能/chinese-composition-coach/
技能/math-homework-diagnosis/
技能/english-homework-diagnosis/
```
