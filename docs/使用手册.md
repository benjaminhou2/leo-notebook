# Leo 学习项目使用手册

## 1. 日常使用入口

学习网站本地地址：

```text
http://127.0.0.1:5173/
```

首版密码配置文件：

```text
config/auth.json
```

当前默认密码：

```text
leo2026
```

## 2. 启动学习网站

进入网站目录：

```bash
cd /Users/ben/Desktop/leo-notebook/网站
```

首次使用或依赖变更后：

```bash
npm install
```

启动本地网站：

```bash
npm run dev -- --port 5173
```

如果只想重新同步资料和配置：

```bash
npm run sync
```

构建检查：

```bash
npm run build
```

## 3. 新增一份作业或试卷的流程

1. 把原始图片放入对应科目的 `原始素材/`。
2. 按命名规范重命名图片。
3. 按学科使用对应技能分析资料：
   - 语文阅读：`$chinese-reading-diagnosis`
   - 语文作文：`$chinese-composition-coach`
   - 数学：`$math-homework-diagnosis`
   - 多学科汇总：`$student-homework-diagnosis`
4. 把家长版诊断、Leo 版讲解或学习页放入对应科目的 `教学分析/`。
5. 根据分析出的薄弱知识点，在对应科目的 `提升习题/` 中为每个知识点创建一个专项习题文件。
6. 更新 `config/content-index.json`：
   - 在 `materialGroups` 中登记原始素材和分析文件。
   - 在 `knowledgePlans` 中登记知识点和习题文件。
7. 运行 `npm run sync`。
8. 打开网站确认首页两部分都已出现新内容。

## 4. 文件命名规则

推荐格式：

```text
YYYY-MM-DD-主题-第1页-原图.jpg
YYYY-MM-DD-主题-诊断与提升方案.md
YYYY-MM-DD-主题-Leo错题讲解与训练单.md
YYYY-MM-DD-主题-Leo错题讲解与训练单.html
YYYY-MM-DD-知识点-提升习题.md
```

日期未知时：

```text
日期不详-主题-原图.jpg
```

处理后避免继续使用 `微信图片_...` 这类泛名称。

## 5. 更新网站首页内容

首页由 `config/content-index.json` 控制。

常改字段：

- `materialGroups`：原始素材、分析文件、Leo 学习页。
- `knowledgePlans`：需要加强的知识点、关联资料、习题文件。
- `subjects`：科目和三层目录位置。

修改后运行：

```bash
cd /Users/ben/Desktop/leo-notebook/网站
npm run sync
```


提醒：首版是明文密码，只适合作为本地轻量访问门。

## 7. 给 Leo 看学习页的原则

- 第一屏直接告诉他今天要学什么。
- 一次只抓 1 个最重要问题。
- 每个任务控制在 5-10 分钟。
- 使用浅暖色，不使用深色压抑页面。
- 不做游戏化奖励，不分散注意力。
- 结尾给一句能记住的自查口诀。

## 8. 常见问题

### 网站没有显示新资料

检查：

1. 是否更新了 `config/content-index.json`。
2. 是否运行了 `npm run sync`。
3. `materialGroups` 和 `knowledgePlans` 中的文件路径是否与真实文件名一致。

### 打开资料链接失败

检查：

1. 文件是否存在于对应科目的三层目录中。
2. `content-index.json` 中路径是否有错别字。
3. 是否重新运行了 `npm run sync`。

### 首页只看到原始素材，看不到习题

检查：

1. `knowledgePlans` 中是否新增了对应知识点。
2. 每个知识点是否填写了 `practiceFiles`。
3. 习题文件是否放在对应科目的 `提升习题/` 中。

### 忘记密码

直接查看或修改：

```text
config/auth.json
```
