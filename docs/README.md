# Leo 学习项目文档中心

这个目录用于保存项目级文档，帮助后续持续维护 Leo 学习资料库、学习网站和本地技能。

## 文档入口

| 文档 | 用途 |
| --- | --- |
| [[项目业务规则]] | 保存 Leo 学习资料处理、命名、输出、HTML 学习页和证据规则 |
| [[本地学习门户系统设计]] | 说明本地学习门户的信息架构、三层目录、配置模型和数据流 |
| [[技术方案手册]] | 说明项目架构、目录职责、配置流转、网站实现和技能关系 |
| [[使用手册]] | 说明日常如何录入资料、生成分析、更新网站、启动网站 |
| [[未来开发计划]] | 记录后续迭代方向、优先级和验收标准 |
| [[资源清单]] | 汇总关键路径、命令、配置文件、技能入口和已接入内容 |

## 维护原则

- `AGENTS.md` 是 Agent 协作和任务路由入口，不承载完整业务规则正文。
- 学习业务细则放在 `项目业务规则.md`。
- `config/` 是学习网站配置唯一真实来源。
- `技能/` 是项目学习技能唯一真实来源；其中 `student-homework-diagnosis` 是通用入口，语文阅读、作文和数学使用细分技能。
- `网站/public/config/` 和 `网站/public/materials/` 是运行副本，不手工维护。
- 新增作业、试卷或作文资料后，应同步更新 `config/content-index.json`，再运行网站同步脚本。
- 面向 Leo 的最终学习内容优先提供浅暖色 HTML 学习页。
