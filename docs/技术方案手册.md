# Leo 学习网站与资料库技术方案手册

## 1. 技术目标

第二阶段采用轻量本地架构，在 8 GB 内存的 macOS 设备上完成：

- 原始素材保存和分页预览。
- 大模型结构化识别与学科诊断。
- 家长人工复核。
- 长期知识画像。
- 两轮训练、自动批改和间隔复习。
- 技能、提示词、模型和任务路由管理。

## 2. 数据职责

| 数据类型 | 唯一真实来源 | 说明 |
| --- | --- | --- |
| 素材、题目、诊断、知识画像、任务、训练结果 | MySQL | 可变化、需要查询和建立关系的业务数据 |
| 原始图片、PDF、Markdown、HTML | 项目文件系统 | 不覆盖原件，数据库只保存路径和校验信息 |
| 网站标题、基础入口 | `config/site.json` | 启动配置 |
| 模型密钥和数据库连接 | `config/auth.json` | 不进入网页公开内容 |
| 默认模型、提示词和任务路由 | `config/ai-defaults.json` | 首次初始化数据 |
| 当前知识目录种子 | `config/knowledge-catalog.json` | 可按教材版本继续扩展 |
| 一阶段门户关系 | `config/content-index.json` | 保留历史静态门户和迁移来源 |

不得把 MySQL 和 JSON 同时作为同一份动态业务数据的写入来源。

## 3. 总体架构

```text

  -> Vite 本地服务与 phase2ApiPlugin
```

## 4. 素材分析链路

```text
上传图片或 PDF
  -> 保存原始文件
  -> PDF 自动分页
  -> 清晰度、重复来源和页序检查
  -> 视觉模型提取题目、答案、批改和证据
  -> 按科目和素材类型选择技能
  -> 文本模型生成薄弱点诊断草稿
  -> 家长逐题确认、修改、驳回或标记需复核
  -> 仅将确认结论写入知识画像
```

智能任务失败时保存失败状态和错误记录，不生成伪造分析。

## 5. 训练质量链路

第一轮以诊断为目标，第二轮读取第一轮错题和错因后进行迁移强化。

发布前检查：

- 题干内部近似重复。
- 第二轮与第一轮近似重复。
- 选择题是否恰好包含 4 个有效且不重复的选项。
- 是否包含“以上都不对”“不确定”等敷衍选项。
- 选项长度是否明显泄露答案。
- 答案、讲解、知识标签和出题依据是否完整。

质量检查未通过时，发布接口返回冲突状态，Leo 端不会读取草稿题目。

## 6. 智能配置体系

### 技能

- 项目 `技能/` 是真实文件来源。
- 数据库保存技能版本、发布状态和变更说明。
- 发布或回退技能版本时，同步写回项目技能文件。
- 全局技能入口继续保持为指向项目目录的符号链接。

### 提示词

- 提示词不再硬编码在业务组件中。
- 每次保存创建新草稿版本。
- 发布和回退不会删除历史版本。
- 模板变量从 `{{变量名}}` 自动提取。

### 模型与路由

- 当前支持智谱视觉模型和 DeepSeek 文本模型。
- 模型配置只保存密钥引用，不保存或显示完整密钥。
- 任务路由根据任务类型、科目和素材类型选择技能、提示词与模型。
- 每次运行记录实际使用的版本、耗时、状态和错误信息。

## 8. 网站运行

在 `网站/` 目录中：

```bash
npm install
node scripts/init-db.mjs
npm run dev -- --port 5173
```

如果端口已占用，Vite 会自动选择下一个可用端口。

构建检查：

```bash
npm run build
```

## 9. 安全与数据边界

- 原始学生资料默认保存在本机。
- 调用外部模型前必须通过已配置任务路由。
- API 密钥只由服务端读取。
- 浏览器运行副本不得包含 MySQL 密码或模型密钥。
- 当前登录方式只适合家庭本地使用。
- 公网开放前必须升级密码存储、会话、传输加密和访问审计。
