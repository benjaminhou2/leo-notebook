# Leo 学习网站与资料库技术方案手册

## 1. 项目目标

Leo 学习项目用于长期沉淀作业、试卷、作文和错题资料，并通过本地技能分析 Leo 的学习情况，生成家长版诊断、Leo 版讲解、专项练习和学习网站展示内容。

当前首版网站定位为“本地学习门户”：

- 本地浏览，不依赖数据库。
- 通过一套本地账号密码进入。
- 内容由 Markdown、HTML、JSON 和图片文件驱动。
- 首页第一部分展示各科原始素材和系统分析。
- 首页第二部分展示各科需要加强的知识点和对应提升习题。
- 页面采用安静、浅暖、低饱和色系。

核心数据流：

```text
原始作业/试卷/作文
  -> 放入对应科目的 原始素材/
  -> Codex 按学科使用对应学习技能分析
  -> 生成 教学分析/ 中的 Markdown 或 HTML
  -> 针对薄弱知识点生成 提升习题/ 中的专项练习
  -> 更新 config/content-index.json
  -> 网站/scripts/sync-config.mjs 同步到 网站/public/
  -> React 网站读取 public/config 并展示门户
```

## 3. 目录职责

### `config/`

项目级配置唯一真实来源。

- `site.json`：网站标题、Leo 信息、主题色、运行时路径。
- `auth.json`：首版本地明文密码。
- `content-index.json`：门户索引，表达原始素材、系统分析、学习页、知识点和习题之间的关系。

### `技能/`

项目级技能库。当前核心技能是：

- `技能/student-homework-diagnosis/`：通用入口和跨学科汇总。
- `技能/chinese-reading-diagnosis/`：语文阅读理解诊断与训练。
- `技能/chinese-composition-coach/`：语文作文写作分析与辅导。
- `技能/math-homework-diagnosis/`：数学作业试卷诊断与训练。

全局 Codex 技能入口应保持为指向项目 `技能/` 下对应目录的软链接，不要复制成多份真实目录。

### `网站/`

React + Vite 静态网站。

- `src/main.jsx`：登录、门户首页、科目资料与知识点展示逻辑。
- `src/styles.css`：浅暖色视觉样式。
- `scripts/sync-config.mjs`：同步根目录配置和资料到 public 运行目录。
- `public/config/`：运行时配置副本，不手工编辑。
- `public/materials/`：运行时资料副本，不手工编辑。

### 学科目录

每科采用三层结构：

- `原始素材/`：原始图片、试卷、作文索引和其他来源资料。
- `教学分析/`：诊断方案、错题讲解、Leo 学习页、训练说明。
- `提升习题/`：按知识点拆分的专项练习文件。

历史专题目录如 `语文/作文部分/` 可继续保留。接入门户时，通过 `content-index.json` 建立与分析和习题的关联。

## 4. 登录方案

首版使用轻量密码门：

- 密码保存在 `config/auth.json`
- 网站启动时同步到 `网站/public/config/auth.json`
- 浏览器读取配置后本地比对
- 登录状态保存在 `sessionStorage`

安全边界：

- 该方案适合本地或家庭轻量访问。
- 明文密码不适合公网强安全认证。
- 如果后续公网部署，需要重新设计认证方案。

## 5. 门户索引方案

网站展示内容来自 `config/content-index.json`。

主要字段：

- `subjects`：科目列表和每科三层目录位置。
- `materialGroups`：原始素材与系统分析的组合。
- `knowledgePlans`：需要加强的知识点、证据资料和对应习题文件。

关键关系：

```text
materialGroups.rawFiles -> 原始素材
materialGroups.analysis.file -> 教学分析
materialGroups.learningLinks -> Leo 学习页或训练单
knowledgePlans.evidenceMaterialIds -> 指向 materialGroups
knowledgePlans.practiceFiles -> 提升习题
```

新增资料时，应先新增或更新 `materialGroups`，再根据分析结果新增或更新 `knowledgePlans`。

## 6. 网站运行流程

在 `网站/` 目录中：

```bash
npm install
npm run sync
npm run dev -- --port 5173
```

打开：

```text
http://127.0.0.1:5173/
```

构建检查：

```bash
npm run build
```

## 7. 视觉与学习体验规范

面向 Leo 的页面应遵守：

- 浅暖色、低饱和、安静学习氛围。
- 不使用黑底、深灰、深蓝、深绿、深红。
- 不加入彩纸屑、声音、计时器、随机奖励或闪烁动画。
- 首页第一屏必须明确展示门户当前接入了哪些资料和知识点。
- 习题任务应短小，通常 5-10 分钟。

## 8. 当前技术债与注意事项

- `auth.json` 使用明文密码，只适合首版本地访问。
- `网站/public/` 和 `网站/dist/` 是生成产物，不应作为配置源。
- 需要补 `validate-content-index` 脚本，自动检查新门户索引断链。
- `npm install` 曾提示 2 个中等风险依赖告警，暂未执行强制修复，避免破坏版本。
