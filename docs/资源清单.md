## 关键配置

| 文件 | 说明 |
| --- | --- |
| `config/site.json` | 网站标题、学生信息、主题配置 |
| `config/auth.json` | MySQL、模型密钥和本地认证配置，只由服务端读取 |
| `config/ai-defaults.json` | 默认模型、提示词和任务路由 |
| `config/knowledge-catalog.json` | 当前年级知识目录种子 |
| `config/content-index.json` | 一阶段门户索引和历史迁移来源 |

## 网站命令

在 `网站/` 目录运行：

```bash
npm install
node scripts/init-db.mjs
npm run sync
npm run dev -- --port 5173
npm run build
```

本地访问：

```text
http://127.0.0.1:5173/
```
