# Leo 学习项目业务规则

本文档保存 Leo 学习项目的业务规则。`AGENTS.md` 只负责路由，具体学习资料处理规则以本文档和 `技能/` 下的项目学习技能为准。

## 1. 学习者默认信息

- 学生：Leo
- 教育体系：中国小学
- 当前阶段：五年级第二学期
- 主要目标：长期跟踪作业、试卷、作文和错题，识别薄弱知识点，生成适合 Leo 的讲解和练习材料。
- 设备环境：macOS，内存 8 GB。优先采用轻量级本地工作流。

如果用户提供了新的年级、学期、教材版本、城市或学校要求，应以用户说明为准，并在分析中说明依据。

## 2. 证据与原始资料保护

- 保留原始证据，不覆盖学生原作、原始照片、原始试卷或人工校对过的转写内容。
- 原始内容、OCR/转写、老师批改信息、错误清单、优化建议和专项练习应分开保存。
- 所有诊断都应能追溯到原图、试卷、批注、分数、历史记录或用户说明。
- 照片内容不清楚时，标记为 `需复核原卷`。
- 不确定的 OCR 或手写识别不得当作确定事实。
- 用户人工修正后的转写内容，是后续分析的当前可信来源。

## 3. 目录与命名规则

常用目录：

- `语文/原始素材/`：语文试卷、作业图片和其他原始资料。
- `语文/教学分析/`：语文诊断、错题讲解、作文总结和 Leo 学习材料。
- `语文/提升习题/`：语文按知识点拆分的专项练习文件。
- `数学/原始素材/`：数学试卷、作业图片和其他原始资料。
- `数学/教学分析/`：数学诊断、错题讲解和 Leo 学习页面。
- `数学/提升习题/`：数学按知识点拆分的专项练习文件。
- `英文/原始素材/`、`英文/教学分析/`、`英文/提升习题/`：英文资料的对应三层目录。
- `语文/作文部分/`：语文作文历史专题资料、转写稿和作文索引，可继续作为作文原始资料来源。
- `技能/`：项目自有可复用技能。
- `config/`：学习网站配置源。
- `docs/`：项目文档中心。
- `网站/`：React/Vite 静态学习网站。

文件命名应包含日期、主题、页码或类型、用途。推荐格式：

- `YYYY-MM-DD-主题-第1页-原图.jpg`
- `YYYY-MM-DD-主题-诊断与提升方案.md`
- `YYYY-MM-DD-主题-Leo错题讲解与训练单.md`
- `YYYY-MM-DD-主题-Leo错题讲解与训练单.html`
- `YYYY-MM-DD-知识点-提升习题.md`
- 日期未知时使用 `日期不详-主题-原图.jpg`

处理后避免继续使用 `微信图片_...` 这类泛泛文件名。图片重命名后，应同步更新 Markdown、HTML 和网站索引中的引用。

## 4. 作业、试卷与作文处理规则

处理作业、试卷、作文、听写、错题或老师反馈时，按学科优先使用细分技能：

- 语文阅读理解、阅读试卷、阅读错题：使用 `$chinese-reading-diagnosis`。
- 语文作文、作文转写、作文批改、作文素材：使用 `$chinese-composition-coach`。
- 数学作业、数学试卷、数学错题：使用 `$math-homework-diagnosis`。
- 多学科混合资料或总体学习画像：使用 `$student-homework-diagnosis`。

分析时优先完成：

- 明确学科、年级/学期、单元、作业类型、分数和来源文件。
- 提取错题、老师批注、失分点、空白步骤、表达不完整处和重复习惯。
- 区分知识点缺口、技能缺口、习惯问题和材料难度问题。
- 按影响程度排序：高频、高失分、影响后续学习的问题优先处理。
- 给出适合小学五年级下学期的练习建议，避免超纲方法。

作文处理需保持以下分层：

- 原文逐字转写
- 图片批改信息
- 发现的错误和可优化清单
- 共性问题分析
- 专项练习建议

## 5. 家长版诊断要求

面向家长的诊断应具体、可执行，不做泛泛评价。通常包括：

- 基本信息
- 主要优点和当前最影响得分的问题
- 按优先级排列的错误类型
- 薄弱知识点和原因判断
- 短期练习安排
- 家长陪练和检查建议

表达方式应避免给孩子贴标签。不要写“粗心、懒、弱”，应改成可观察行为，例如“写完后缺少二次检查”“对话标点还没有形成固定模板”。

## 6. Leo 版讲解要求

面向 Leo 的内容应短、清楚、温和，帮助他自己掌握思考方法。

每个具体错题或问题优先讲清：

- 这道题在问什么
- 证据、条件或关键句在哪里
- 这是几分题，应该写几点或几步
- Leo 当时卡在哪一步
- 下次可以套用的答题方法或检查方法
- 一个小练习
- 一句自查提示

语文阅读优先使用：

- 这道题问你什么？
- 原文哪一句能支持你的答案？
- 这是几分题，应该写几点？

数学题优先使用：

- 题目给了什么？
- 题目问什么？
- 哪个量是单位 1？
- 数量关系是什么？
- 算完怎么检查？

## 7. 学科重点

语文作文重点看：

- 审题与立意：是否扣题，中心是否明确。
- 结构：开头、事件展开、细节、结尾点题。
- 语言：错别字、病句、词语搭配、的地得、标点、对话格式。
- 内容：是否有具体动作、心理、语言、环境描写。
- 修订能力：哪些问题写完自查能发现。

语文基础与阅读重点看：

- 字词、句子、修辞、概括、信息提取、中心理解、开放表达。
- 五年级下重点关注段意、人物品质、说明顺序、修辞效果和答案完整度。

数学重点看：

- 概念不清、公式不会用、计算错误、单位错误、审题遗漏、步骤不完整、应用题建模。
- 五年级下优先围绕分数、小数、体积/表面积、数量关系、统计和多步应用题。

英语重点看：

- 词汇、拼写、句型、时态、单复数、阅读细节、听力识别和写作表达。
- 五年级下以短句型、教材词汇和常见表达为主。

## 8. HTML 学习页与文件展示规则

当最终内容主要给 Leo 阅读时，优先制作自包含本地 `.html` 页面，除非用户明确要求只要 Markdown。

设计要求：

- **禁止浏览器直读 Markdown**：由于直接在浏览器中打开 `.md` 文件容易产生排版错乱和中文乱码，系统内所有文件展示必须通过 HTML 的方式呈现。对于必要的 Markdown 格式数据，应通过系统内的 HTML 渲染器组件渲染，禁止链接直接跳转加载原始 Markdown 文本。
- 使用内联 CSS，不依赖外部网络资源。
- 页面第一屏直接告诉 Leo 今天要学什么。
- 使用浅暖色、低饱和、安静学习氛围。
- 优先使用柔和奶油色、暖白色、浅天蓝色、浅薄荷色、浅桃色和柔和黄色。
- 不使用黑色背景、深灰面板、深色代码块、深蓝、深绿、深红或大面积高饱和色块。
- 不使用彩纸屑、声音、计时器、随机奖励、闪烁动画或无关图片。
- 公式块、答案块、步骤卡片使用浅色底纹，文字必须清楚可读。
- 条件允许时，链接回原始图片、Markdown 笔记或诊断来源。

## 9. 练习设计规则

- 默认每天 10-20 分钟。
- 一次练习只聚焦一个主要薄弱点。
- 优先用旧作业中的真实错误做练习来源，再补充新题。
- 练习要有明确验收标准，例如“10 句中改对 8 句”。
- 同一薄弱点应在 2-3 天后复现一次，形成间隔复习。
- 不设计超出当前年级明显范围的训练，除非用户明确要求拓展。

## 10. 完成前检查

- 新建文件是否位于正确目录。
- 原始图片、学生原文和人工校对内容是否没有被覆盖。
- 图片重命名后，相关 Markdown、HTML 和网站索引是否同步更新。
- HTML 中是否没有 `{{...}}` 这类模板占位符。
- HTML 是否无断链、无深色视觉系统。
- 不确定来源是否标注为 `需复核原卷`。
