# Leo 学习项目未来开发计划

> 本文档记录第二阶段完成后的校准事项和后续路线。产品范围与验收标准以 `项目需求说明.md` 为统一基线。

## 当前状态

截至 2026-06-07：

- 第一阶段的本地学习门户和历史资料已保留。
- 第二阶段核心功能已实现。
- 动态业务数据以 MySQL 为唯一真实来源。
- 原始图片、PDF、Markdown 和 HTML 继续由本地文件系统保存。
- 技能、提示词、模型和任务路由已经进入可版本化管理体系。
- 一阶段历史题已迁移为待复核草稿，不会绕过质量检查直接发布。

## 当前校准事项

| 优先级 | 事项 | 验收方向 |
| --- | --- | --- |
| P0 | 确认语文、数学、英文教材版本 | 学生档案和知识目录不再显示 `待确认` |
| P0 | 补齐数学期末综合自测缺失原图 | 数据一致性检查不再报告该文件缺失 |
| P0 | 用近期真实素材校准四个学科技能 | 结构化题目、证据和薄弱点结论可被家长直接采用 |
| P0 | 重生成一阶段历史训练题 | 重复率、敷衍选项、答案和讲解全部通过质量检查 |
| P1 | 补录学校教学进度和老师要求 | 出题范围与当前课堂进度一致 |
| P1 | 建立每周一次的报告复盘习惯 | 周报能够稳定形成“改善、持续问题、下周重点” |
| P1 | 为关键提示词建立固定测试样例 | 提示词升级前后可比较，不只依靠主观判断 |

## 第三阶段方向

### 1. 真实数据评估集

- 为语文阅读、作文、数学和英文分别挑选代表性素材。
- 保存家长确认后的标准结构、标准薄弱点和标准训练题。
- 对技能、提示词和模型版本进行可重复比较。
- 记录准确率、复核修改量、重复率和发布通过率。

### 2. 跨学段知识体系

- 在六年级、初中和高中切换时保留历史证据。
- 建立知识点前置关系和学段映射。
- 区分“当前教材要求”和“长期能力问题”。
- 支持教材版本切换后的目录迁移。

### 3. 家庭远程访问

触发条件：

- 需要在非本机设备访问。
- 需要多位家庭成员共同维护。

升级要求：

- 使用服务端会话和安全密码存储。
- 增加访问日志、备份恢复和传输加密。
- 明确原始学生资料允许发送到哪些模型服务。
- 公网开放前完成隐私与密钥安全检查。

### 4. 自动化与提醒

- 定时检查到期复习任务。
- 每周生成家长报告草稿。
- 模型任务失败时提醒重试。
- 数据一致性检查出现新增问题时提醒家长。

## 暂不推进

- 多家庭、多学校和商业化多租户。
- 排名、积分、抽奖等重游戏化机制。
- 无家长确认的全自动知识标签。
- 本地部署重型大模型或向量集群。
