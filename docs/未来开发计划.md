# Leo 学习项目未来开发计划

## 版本路线

### v1：本地学习门户

状态：已按新目标重构首版。

目标：

- 使用一套本地账号密码，账号密码由 `config/auth.json` 配置。
- 不使用数据库，所有资料、索引和配置由 Markdown、HTML、图片和 JSON 文件驱动。
- 登录后首页分成两部分：
  - 第一部分：按科目展示各科原始素材链接，以及系统基于每份原始素材生成的分析结果。
  - 第二部分：按科目展示系统分析后给出的需要加强知识点清单，并连接到每个知识点对应的提升习题文件。
- 使用 `config/` 作为唯一配置中心，网站只读取运行副本。
- 每科采用三层资料管理：
  - `原始素材/`：保存该科原始图片、试卷、作文索引或其他来源材料。
  - `教学分析/`：保存系统对原始素材的诊断、错题讲解、Leo 学习页或训练说明。
  - `提升习题/`：保存按知识点拆分的专项习题文件。
- 分析资料与原始素材要建立引用关系，知识点清单与习题文件要建立引用关系。

验收标准：

- 能本地打开网站并用配置中的密码登录。
- 登录后首页第一部分能清楚展示“科目 -> 原始素材 -> 系统分析”的关系。
- 登录后首页第二部分能清楚展示“科目 -> 需要加强的知识点 -> 对应习题文件”的关系。
- 已接入资料至少包含数学第五六单元、语文第三单元试卷、语文作文总结三类材料。
- 每个已接入知识点都有单独习题文件，而不是只写在网页卡片里。
- `config/content-index.json` 能表达原始素材、分析资料、学习页、知识点建议和习题文件之间的关联。
- `网站/public/config/` 和 `网站/public/materials/` 只作为运行副本，不手工维护。
- 页面保持浅暖色、低饱和、安静学习氛围，不使用深色视觉系统。

### v1.1：内容录入流程增强

目标：

- 固化“新增原始素材 -> 生成教学分析 -> 拆分提升习题 -> 更新门户索引”的日常流程。
- 为 `config/content-index.json` 增加校验脚本，确保新门户关系不断链。
- 给每科三层目录增加 README 或索引说明，降低后续维护成本。

建议新增：

- `网站/scripts/validate-content-index.mjs`
- 自动检查 `materialGroups.rawFiles`、`analysis.file`、`learningLinks` 和 `knowledgePlans.practiceFiles` 是否存在。
- 自动检查每个知识点是否至少关联一份原始素材和一个习题文件。
- 自动提示仍停留在旧目录但已经接入门户的资料，方便后续逐步迁移。

### v1.2：门户学习体验优化

目标：

- 让 Leo 登录后能更快知道“今天先练哪一个知识点”。
- 在知识点卡片中增加轻量完成状态。
- 支持按科目、优先级和知识点查看资料。

限制：

- 不做复杂游戏化。
- 不引入数据库。
- 本地完成状态可先使用 `localStorage`。
- 完成状态只辅助学习，不作为正式成绩记录。

### v1.3：家长总览

目标：

- 增加家长视角页面。
- 展示各科薄弱点、最近原始素材、最近分析、连续问题、建议陪练重点。
- 支持按 P0/P1/P2 查看问题优先级。

可展示指标：

- 高频知识点问题。
- 最近 7 天练习建议。
- 已改善问题。
- 需要复核原卷的项目。
- 已有习题但还没有生成 Leo HTML 学习页的项目。

### v2：内容生成与门户联动

目标：

- Codex 分析作业后，自动更新 `config/content-index.json`。
- 自动把新资料归入对应科目的三层目录。
- 自动生成 Leo 版 HTML 学习页或专项习题文件。
- 自动同步到网站 public 运行目录。

建议实现：

- 在各学科诊断技能中补充“门户索引更新”步骤，并由 `$student-homework-diagnosis` 负责跨学科汇总。
- 生成内容后自动给出：
  - 新增原始素材
  - 新增教学分析
  - 新增提升习题
  - 更新的知识点
  - 需要人工复核的链接

### v3：公网访问与安全升级

触发条件：

- 需要让家庭成员在非本机设备访问。
- 需要部署到公网。

升级方向：

- 不再使用明文前端密码。
- 使用托管平台访问保护、服务端认证或家庭局域网方案。
- 重新评估学生资料隐私边界。

## 优先级建议

| 优先级 | 事项 | 原因 |
| --- | --- | --- |
| P0 | 内容索引校验脚本 | 新门户依赖多层引用关系，断链会直接影响使用 |
| P0 | 三层目录录入流程固化 | 保证原始素材、分析资料、提升习题不再混放 |
| P0 | Codex 分析后自动更新门户索引 | 减少手工维护成本，避免漏挂习题 |
| P1 | 门户筛选与完成状态 | 方便 Leo 每天知道先做什么 |
| P1 | 家长总览页 | 方便长期跟踪学习趋势 |
| P2 | 公网部署 | 当前首版以本地为主，暂不急 |

## 下一步建议

1. 先补 `validate-content-index` 脚本，检查新门户索引中的所有文件引用。
2. 再升级语文阅读、语文作文和数学三个细分技能，让它们生成分析后能同步更新 `materialGroups` 和 `knowledgePlans`。
3. 为 `数学/原始素材`、`数学/教学分析`、`数学/提升习题` 等目录补简短 README，明确每层放什么。
4. 等资料量超过 10 份后，再做筛选、完成状态和家长总览页。
