# 给 Leo 的数学错题讲解与训练单

Leo，这次数学卷子里，你不是“不会分数”，而是有几道题在列式前少想了一步：题目到底问的是“占几分之几”，还是“实际有多少”。

以后遇到分数应用题，先别急着算，先问自己 4 个问题：

1. 题目给了什么？
2. 题目问什么？
3. 哪个量是单位 1？
4. 算完结果合理吗？

## 第 1 题：花圃里的玫瑰占几分之几

### 这题先别急

题目说：整个花圃面积是 `5/6` 公顷，牡丹占总面积的 `2/5`，百合占总面积的 `1/3`，其余是玫瑰。问：玫瑰占总面积的几分之几？

这题最容易掉进去的坑是：看到 `5/6` 公顷，就把它也拿来减。

### 第 1 步：题目问什么？

它问的是：

```text
玫瑰占总面积的几分之几
```

注意，是“占几分之几”，不是“玫瑰有多少公顷”。

### 第 2 步：单位 1 是谁？

因为题目问“占总面积”，所以整个花圃就是单位 1。

你可以把花圃想成一个完整的游戏地图。牡丹占走一块，百合占走一块，剩下的地图就是玫瑰。

### 第 3 步：怎么列式？

```text
玫瑰占比 = 1 - 牡丹占比 - 百合占比
1 - 2/5 - 1/3
= 15/15 - 6/15 - 5/15
= 4/15
```

所以玫瑰占总面积的 `4/15`。

### Leo 这次差在哪一步？

你把 `5/6` 公顷也放进算式里了。可是 `5/6` 是实际面积，`2/5` 和 `1/3` 是占比，它们不是同一种东西，不能直接减。

### 下次遇到同类题

看到“占总数的几分之几”，先把总数看作 `1`。

### 你来试一题

一个班的活动时间中，阅读占 `1/4`，运动占 `1/3`，其余是自由活动。自由活动占总时间的几分之几？

自查：你的算式里应该出现 `1 - ... - ...`。

## 第 2 题：蔬菜地里的“其他”怎么算

表格里有这些信息：

- 黄瓜占 `1/8`
- 西红柿占 `1/6`
- 白菜占 `3/8`
- 辣椒占 `1/12`

### 问法 1：黄瓜和白菜共占几分之几？

看到“共占”，就是把两部分合起来：

```text
1/8 + 3/8 = 4/8 = 1/2
```

### 问法 2：其他蔬菜占几分之几？

“其他”不是表格里已经写出来的某一项，它是剩下的部分。

先算已知蔬菜一共占多少：

```text
1/8 + 1/6 + 3/8 + 1/12
= 3/24 + 4/24 + 9/24 + 2/24
= 18/24
= 3/4
```

再用整个菜地 `1` 减掉已知部分：

```text
1 - 3/4 = 1/4
```

所以其他蔬菜占 `1/4`。

### 问法 3：白菜比辣椒多占几分之几？

看到“比……多”，就是大的减小的：

```text
3/8 - 1/12
= 9/24 - 2/24
= 7/24
```

### 下次遇到同类题

你可以先把题目最后一句圈出来：

- 共占：加法
- 其他/剩下：`1 - 已知部分`
- 比谁多：减法

### 你来试一题

一张学习计划表中，数学占 `1/5`，语文占 `1/4`，英语占 `1/10`，其他时间占几分之几？

自查：先把已知的三项加起来，再用 `1` 减。

## 第 3 题：布料题要看清“用去”还是“一共有”

这道题图片里有些笔迹重叠，但能看出它是布料问题：做上衣用去一部分，做裤子用去一部分，还剩一部分。

这类题最关键的不是先算，而是先看最后一句。

### 如果题目问“一共用去多少米”

只加已经用掉的两部分：

```text
上衣用去 + 裤子用去
```

剩下的部分不用加进去。

### 如果题目问“这块布料原来一共有多少米”

就要把用掉的和剩下的都加起来：

```text
上衣用去 + 裤子用去 + 还剩
```

### 一个小例子

你有一笔零花钱，买文具用了 10 元，买本子用了 6 元，还剩 4 元。

- 问“一共用了多少元”：`10 + 6`
- 问“原来一共有多少元”：`10 + 6 + 4`

数学应用题也是这样，最后一句问什么，算式就跟着它走。

### 你来试一题

一根彩带，做装饰用去 `1/3` 米，做书签用去 `1/4` 米，还剩 `1/6` 米。

1. 一共用去多少米？
2. 这根彩带原来一共有多少米？

自查：第 1 问不要加“还剩”，第 2 问要加“还剩”。

## 第 4 题：统计图要先求总，再求占比

统计图题不是只看一个数就结束。只要题目问“占学习总时间的几分之几”，就一定要先求总时间。

### 第 1 步：读出每个时间

比如一名同学的学习时间分成：

```text
看书时间 + 做题时间 + 反思时间
```

### 第 2 步：求总时间

```text
学习总时间 = 看书时间 + 做题时间 + 反思时间
```

### 第 3 步：求占比

```text
反思时间占比 = 反思时间 / 学习总时间
```

### 下次遇到同类题

只要看到“占总时间的几分之几”，就先在草稿纸上写：

```text
总时间 = ____ + ____ + ____
占比 = 某一项 / 总时间
```

### 你来试一题

小明今天学习 6 小时，其中看书 2 小时，做题 3 小时，整理错题 1 小时。

整理错题时间占学习总时间的几分之几？

自查：答案应该是 `1/6`，因为总时间是 6 小时。

## Leo 的分数应用题自查口诀

```text
先看问什么，
再找单位 1；
占比用 1 减，
数量别乱混；
问共就相加，
问差就相减；
算完写答句，
单位别忘记。
```
