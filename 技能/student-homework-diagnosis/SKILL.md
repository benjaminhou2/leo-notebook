# 学生作业诊断

## 概览

本技能现在作为通用入口和跨学科汇总入口。用户给出混合材料、没有明确学科，或要求综合分析多个学科时，使用本技能将孩子的作业资料转化为结构化诊断和可执行提升方案。

如果任务已经明确属于单一领域，优先分流到更精细的学科技能：

| 任务类型 | 优先使用 |
| --- | --- |
| 语文阅读理解、阅读试卷、阅读题错因、三问法训练 | `$chinese-reading-diagnosis` |
| 语文作文、作文原图、作文转写、作文批改、写作训练 | `$chinese-composition-coach` |
| 数学试卷、数学作业、数学错题、应用题、计算、几何、统计 | `$math-homework-diagnosis` |
| 多学科混合资料、总体学习画像、跨学科趋势 | `$student-homework-diagnosis` |

本技能仍支持三类输出：

- 家长版诊断：帮助家长理解错误模式、薄弱知识点和练习优先级。
- 孩子版讲解：帮助孩子理解具体错误，能独立解决类似问题，并建立可复用的思考路径。
- 儿童友好 HTML 页面：把孩子版讲解转化为聚焦、清晰、有视觉引导的阅读页面，比 Markdown 更易读，但仍以学习为中心。

除非用户提供其他年级、学期、教材版本、城市、考试目标或学校要求，否则默认学习者为中国教育体系小学五年级下学期。

工作流程必须以证据为基础：保留学生原始作品，把订正与分析分开，并将每一条诊断连接到可观察的错误、老师批注、分数或重复模式。

## 核心流程

1. 识别学习者背景：年级、学期、学科、单元、作业类型、分数、老师批注和来源文件。缺失时可根据文件名和内容谨慎推断，并标明假设。
2. 保留原始资料：不要在原文中直接改写或“修正”学生内容。把订正建议、优化答案和练习建议放在单独章节或文件中。
3. 提取证据：收集原始错误、老师批改痕迹、评分要求、错误答案、步骤不清、理由缺失和重复习惯。
4. 按类型归类错误：
   - 知识点缺口：概念、公式、语法、词汇、阅读方法、写作结构。
   - 技能缺口：审题、计算、表达、推理、书写、标点、修订、检查。
   - 习惯缺口：抄写不细、漏单位、没有最后检查、时间管理不稳。
   - 发展阶段不匹配：材料太容易、太难或超出当前年级范围。
5. 按影响程度排列薄弱点：
   - P0：高频、高失分、会影响后续学习。
   - P1：反复出现但范围较局部。
   - P2：偶发的表达或完善问题。
6. 推荐符合年级阶段的练习。对当前默认学习者，语文、数学和英语任务应适合小学五年级下学期。除非用户明确要求，否则避免使用初中阶段方法。
7. 生成家长友好的总结和具体练习计划。
8. 当用户要求“给孩子看”“孩子能看懂”“错题讲解”“解题思维”“三问法”“训练单”等孩子版材料时，把诊断转化为孩子可直接阅读的题目级讲解。
9. 当最终输出主要给孩子阅读时，除非用户明确只要 Markdown，否则优先生成自包含的儿童友好 HTML 页面。阅读 `references/child-facing-html-output.md`。
10. 当用户要求 HTML、网页、更适合孩子阅读、不想看 Markdown、更有吸引力等呈现升级时，把 HTML 页面作为主要孩子版交付物。

## 年级范围

当任务涉及选择或设计知识点练习时，阅读 `references/china-primary-scope.md` 以确认年级要求。尤其在以下场景使用：

- 用户询问内容是否适合孩子当前年级。
- 需要创建专项训练素材。
- 需要区分知识缺口和习惯性错误。
- 孩子升入新年级或新学期，练习计划需要随之调整。

默认当前画像：

- 学段：中国小学
- 年级：五年级
- 学期：下学期
- 主要诊断语气：支持、具体、家长友好、不羞辱孩子。

## 孩子版讲解模式

当用户要求孩子可读的讲解、错题讲解、思维路径或 Leo 可以直接使用的练习材料时，阅读 `references/child-facing-explanations.md`。

使用这个模式把具体错误转化为清晰的学习时刻：

- 直接对孩子说话，使用简短、温和、符合年龄的中文。
- 一次解释一个具体错误，不要把孩子淹没在完整家长诊断里。
- 先展示思考路径，再给最终答案。
- 阅读题优先使用流程：“这道题问你什么？原文哪一句能支持你的答案？这是几分题，应该写几点？”
- 作文题展示如何发现并修改一个句子、一类标点或一个细节缺口。
- 数学题展示题目给了什么、问什么、应使用什么数量关系、怎样检查答案。
- 英语题展示句型、关键词、常见陷阱和一个短小替换练习。
- 可以加入小学孩子熟悉的简短例子，例如游戏地图、积木、课堂场景、运动战术、侦探线索或日常购物，但例子要短。
- 每个讲解以一个小练习和一句自查规则收尾。
- 如果输出是给 Leo 直接阅读的，优先生成或提供 HTML 学习页；Markdown 只在有必要时作为来源笔记。

## 儿童友好 HTML 呈现模式

当孩子版输出需要比 Markdown 更易读，或需要交付 HTML 页面时，阅读 `references/child-facing-html-output.md`。对直接给孩子阅读的最终反馈，除非用户另有说明，这是默认优先呈现方式。

使用该模式提升可读性和学习动力，但不要把学习内容做成娱乐产品：

- 在相关学科目录中生成自包含 `.html` 文件，通常放在 Markdown 诊断或训练单旁边。
- 需要时以 `assets/child-feedback-template.html` 为起点。
- 页面必须以学习为先：清晰分区、短段落、明确视觉层级、步骤卡片、检查清单和小练习块。
- 避免分散注意力的游戏化：不要使用彩纸屑、声音、计时器、随机奖励、闪烁动画、过多徽章或无关图片。
- 使用明亮、愉快、低饱和配色。优先使用柔和奶油色、暖白色、浅天蓝、浅薄荷、浅桃色和柔和黄色。
- 不使用深色视觉系统：不要黑色背景、深灰面板、深色代码块、深蓝、深绿、深红或大面积高饱和色块。
- 颜色要平静且有目的。用浅色标出“题目问什么”“关键一步”“下次这样做”“自己试一题”，同时保证文字容易阅读。
- 优先做单页聚焦学习，而不是很长的装饰页面。对一张试卷，选择最重要的 2-4 个错误模式。
- 保留证据：条件允许时链接回来源图片或 Markdown 笔记，不隐藏不确定 OCR 或不清楚的照片区域。

## 学科指导

### 语文作文

至少从这些层面分析：

- 审题与立意：是否扣题，中心是否明确。
- 结构：开头、事件展开、细节、结尾点题。
- 语言：错别字、病句、词语搭配、的地得、标点、对话格式。
- 内容：是否有具体动作、心理、语言、环境描写。
- 修订能力：哪些问题写完自查能发现。

作文输出保持以下分离：

- 原文逐字转写
- 图片批改信息
- 发现的错误和可优化清单
- 共性问题分析
- 专项练习建议

### 语文基础与阅读

把问题归类为字词、句子、修辞、概括、信息提取、中心理解、开放表达。五年级下重点关注段意、人物品质、说明顺序、修辞效果和答案完整度。

### 数学

把错误归类为概念不清、公式不会用、计算错误、单位错误、审题遗漏、步骤不完整、应用题建模。五年级下练习应围绕分数、小数、体积/表面积、方程或数量关系、统计、多步骤应用题，并与学生当前材料对齐。

### 英语

把错误归类为词汇、拼写、句型、时态、单复数、阅读细节、听力识别和写作。五年级下练习应短小、基于句型，并默认贴合教材词汇，除非用户要求拓展。

## 练习设计规则

练习要短到真的能完成：

- 默认每日任务 10-20 分钟。
- 一次练习只聚焦一个主要薄弱点。
- 包含可见验收标准，例如“10 句中改对 8 句”或“一篇作文找出 5 个的地得”。
- 优先使用旧作业错误作为练习来源，再创建新题。
- 包含间隔复习：同一薄弱点应在 2-3 天后再次出现。

每个练习计划都要说明：

- 为什么这个点重要。
- 练什么。
- 家长怎么检查。
- 什么算有进步。

## 长期跟踪

分析多次作业时，根据已有证据持续更新学习画像：

- 稳定优势
- 反复薄弱点
- 最近改善的问题
- 新风险
- 推荐的下一个重点

如果工作区中包含索引文件或历史总结，先阅读它们，再生成新的诊断。优先更新或引用标准总结，避免创建彼此脱节的重复笔记。

## 安全与语气

不要给孩子贴“粗心、懒、弱”等标签。描述可观察习惯，例如：“写完后缺少二次检查”“对话标点还没有形成固定模板”“常见词复查不足”。

不要过度训练。如果计划对 8 GB Mac 家庭工作流或小学生来说太重，就缩小成更轻的日常安排。

当课程范围不确定时，说明你的推断；只有当教材版本或学校单元会改变练习材料时，才询问用户。
