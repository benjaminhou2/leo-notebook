# 孩子版讲解参考

当创建给孩子直接阅读的材料时使用本参考。目标不只是告诉孩子正确答案，而是让孩子理解思考路径，下一次能独立解决类似问题。

默认学习者：中国教育体系小学五年级下学期。讲解要具体、简短、鼓励。

## 核心原则

- 直接对孩子说话，例如：“Leo，这题你已经找到方向了，还差一步……”
- 使用简单中文和短段落。避免“能力缺陷”“低阶错误”等家长视角标签。
- 先解释思考路径，再给优化后的答案。
- 从学生原始错误出发，但不要羞辱孩子。
- 每个部分只聚焦一道题或一个小模式。
- 优先使用“你下次可以这样想”，而不是“你应该”。
- 加一个很小的练习任务，让孩子立刻试用这个方法。
- 单道错题讲解通常控制在 600-1000 个中文字符，除非用户要求更深入。

## 通用讲解框架

```markdown
# 给 Leo 的错题讲解

## 这题先别急
用一句话告诉 Leo：这题不是不会，而是哪一步还没有想完整。

## 第 1 步：题目问什么？
把题目要求翻译成孩子听得懂的一句话。

## 第 2 步：证据或条件在哪里？
阅读题找原文句子；数学题找已知条件；英语题找关键词；作文题找原句或上下文。

## 第 3 步：要写几点或几步？
结合分值、题干中的"几方面/为什么/怎样"、空格数量、答题线长度判断答案容量。

## Leo 这次差在哪一步？
指出具体卡点，例如"只写了结论，少了理由"、"找到了一个方面，少找了第二个方面"。

## 更稳的答法
给出适合当前年级的答案，不拔高到初中表达。

## 小例子
用一个孩子熟悉的类比说明思路。

## 你来试一题
给一个很短的同类练习。

## 自查口诀
给一句能记住的话。
```

## 语文阅读题

默认使用“三问法”：

1. 这道题问你什么？
2. 原文哪一句能支持你的答案？
3. 这是几分题，应该写几点？

常见题型：

- “为什么”题：答案通常需要“原因 + 结果”或“原因 1 + 原因 2”。
- “体现了什么”题：答案通常需要“人物/事物特点 + 原文证据”。
- “哪几个方面”题：数清楚题干中的“几个”，每个方面单独写。
- “词语意思”题：先看词语本义，再看它在句子里的具体意思。
- “句子还原”题：先看前一句和后一句，找能接上的关键词、代词、顺序词、转折词。

适合孩子的例子：

- 阅读像走游戏地图：答案不是猜出来的，而是由文中的线索标出来的。
- 两分题像两块积木：只放一个，房子就不稳。
- “为什么”题像解释一次游戏操作：只说“我赢了”不够，还要说“因为我守住了关键位置”。

## 语文作文

作文讲解不要默认重写整篇，除非用户要求。优先选择看得见的模式：

- 错别字：展示原词、正确词和一个记忆方法。
- 病句：说明句子哪里卡住，再保留学生原意进行修改。
- 标点：展示一个可重复使用的规则，例如对话标点或分句停顿。
- 内容空：展示哪里可以增加动作、语言、心理、神态、环境。
- 扣题：指出哪句话应回到题目中心。

推荐孩子版框架：

```markdown
## 这句话哪里卡住了
- 原句：
- 问题：
- 可以这样改：
- 为什么这样更清楚：
- 你仿写一句：
```

## 数学题

使用四步路线：

1. 题目给了什么？
2. 题目问什么？
3. 这两个量之间是什么关系？
4. 算完怎么检查？

除非用户要求拓展，否则方法应保持在当前年级范围内。五年级下优先关注分数、小数、体积、表面积、方程或数量关系、统计，以及与学校材料一致的多步骤应用题。

适合孩子的例子：

- 多步骤应用题像闯关：每一步都会打开下一条线索。
- 单位像盒子上的标签：标签错了，答案看起来对也用不上。

## 英语题

使用简短的句型讲解：

1. 这题考哪个句型或词？
2. 关键词在哪里？
3. 容易掉进哪个坑？
4. 换一个相似句子再练一次。

除非用户要求拓展，否则例句应贴合教材级词汇和句型。

## 语气规则

可以使用：

- “这题你不是完全不会，你已经找到了一部分。”
- “下一次先别急着写答案，先把题目翻译成一句简单的话。”
- “这类题最稳的方法是……”

避免使用：

- “你太粗心了。”
- “这个很简单。”
- “你应该早就会。”
- 孩子无法行动的长篇成人分析。

## 输出选择

如果用户同时需要家长版和孩子版，清楚分开：

- `家长版诊断与陪练建议`
- `Leo 版错题讲解与练习单`

如果用户只要求孩子版材料，不要加入很长的家长诊断。只保留孩子学习所需的最少背景。
