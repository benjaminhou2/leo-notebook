# 孩子版 HTML 输出参考

当作业诊断或错题讲解需要以 HTML 页面交付给孩子直接阅读时，使用本参考。

目标是提高注意力，而不是娱乐化。反馈应比纯 Markdown 更容易浏览、更温暖、不枯燥，同时让孩子的注意力仍集中在解题方法上。

## 何时使用

当用户提到以下需求时，使用 HTML 输出：

- HTML、网页、页面、浏览器打开
- 给孩子看、孩子能看懂
- Markdown 太枯燥、不方便阅读
- 更有吸引力、更适合小孩阅读
- 输出学习页、训练页、错题讲解页

如果只是给家长看的诊断，Markdown 仍然可以接受，除非用户要求 HTML。对直接给孩子看的最终反馈，默认优先 HTML，因为它比长篇 Markdown 更适合小学生阅读。

## 输出约定

- 在相关作业目录中创建自包含 `.html` 文件。
- 使用内联 CSS，不依赖外部网络资源。
- 条件允许时，用相对链接指向来源图片或 Markdown 笔记。
- 如果来源照片或手写内容不清楚，显示“需复核原卷”，不要假装确定。
- 普通作业聚焦 1-3 个高价值错误；试卷聚焦 2-4 个错误模式。
- 不添加无关游戏、奖励、卡通、音乐、计时器或闪烁动画。

## 视觉风格

使用平静、明亮、易读的学习页风格：

- 标题较大，但不要幼稚。
- 开头用短句告诉孩子今天重点看什么。
- 一个紧凑的“错题地图”展示主要薄弱点。
- 用步骤卡展示思考路径。
- 用提示框展示“关键提醒”和“下次这样做”。
- 页面末尾放一个小练习区。
- 适合打印。

配色方向：

- 整体页面：柔和奶油色或非常浅的暖色背景。
- 主面板：暖白色。
- 思考路径：浅天蓝，不用深蓝。
- 正确方法或自查：浅薄荷，不用深绿。
- 常见陷阱：浅桃色或浅黄色，不用橙棕色。
- 提醒：柔和珊瑚色或浅玫瑰色即可，绝不使用大红。
- 公式或答案框：浅色底纹并保证文字可读，不用黑色或深色代码块。
- 正文文字：使用易读的暖色墨色，不用纯黑，也不要大量深灰。

避免：

- 深色模式
- 黑色、炭黑或深灰背景
- 公式后面的大块深色背景
- 深蓝、深绿、深红或高饱和红
- 整页装饰背景
- 厚重渐变
- 过多图标或 emoji
- 与题目无关的随机插图
- 多层嵌套卡片
- 会导致横向滚动的长表格

## 页面结构

推荐结构：

```html
<main class="page">
  <header class="hero">
    <p class="eyebrow">Leo 的错题讲解</p>
    <h1>今天先学会：看清题目到底问什么</h1>
    <p class="summary">这页只练一个核心能力：先判断单位 1，再决定怎么列式。</p>
  </header>

  <section class="map">
    <h2>错题地图</h2>
    <ol>
      <li>题目问的是占比还是实际数量</li>
      <li>单位 1 是谁</li>
      <li>算完怎么检查</li>
    </ol>
  </section>

  <section class="lesson">
    <h2>第 1 题：题目问什么</h2>
    <div class="step">...</div>
  </section>

  <section class="practice">
    <h2>5 分钟小练习</h2>
    <p>...</p>
  </section>
</main>
```

## 给孩子写内容的规则

- 直接对孩子说话。
- 一个段落通常 1-3 个短句。
- 使用具体动作词：圈出、写下、比较、检查。
- 把抽象建议变成看得见的动作。
- 把公式或答题框放进浅色高亮块。
- 使用“下次这样做”，而不是“你应该”。

推荐写法：

```text
先圈最后一句。它问"占几分之几"，所以总量先看作 1。
```

避免写法：

```text
该题反映出学生分数应用题数量关系建模能力不足。
```

## HTML 模板使用

创建页面时，优先从 `assets/child-feedback-template.html` 开始。替换所有 `{{placeholder}}` 字段，并删除没有使用的部分。

模板刻意保持简单：

- 无 JavaScript
- 无外部资源
- 适配手机
- 适合打印
- 聚焦阅读和练习

如果用户要求更强的互动性，互动也应保持教育性和轻量，例如可折叠的“看提示”区域。除非用户明确要求，否则不要加入游戏机制。

## 文件命名

使用描述清楚的中文文件名：

```text
YYYY-MM-DD-试卷或作业主题-Leo错题讲解.html
YYYY-MM-DD-试卷或作业主题-Leo专项训练.html
```

如果已经存在孩子版 Markdown 笔记，使用相同主文件名：

```text
2026-05-23-第五六单元综合练习-Leo错题讲解与训练单.md
2026-05-23-第五六单元综合练习-Leo错题讲解与训练单.html
```

## 质量检查

完成前确认：

- HTML 可以作为独立本地文件打开。
- 没有旧的损坏图片链接或笔记链接。
- 长公式和中文文本在手机宽度下不溢出。
- 页面没有分散注意力的动画或无关视觉元素。
- 页面不使用黑色、深灰、深蓝、深绿、深红作为视觉系统。
- 公式块使用浅色背景，不使用黑色或深色代码块样式。
- 第一屏告诉孩子今天具体要学什么。
