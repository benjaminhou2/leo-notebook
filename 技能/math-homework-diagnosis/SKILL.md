# 数学作业与试卷诊断辅导

## 适用范围

当任务聚焦数学试卷、数学日常作业、口算笔算、应用题、几何图形、统计图、错题整理或数学知识点补弱时，使用本技能。

默认学习者为中国教育体系小学五年级下学期。若用户提供新的年级、学期、教材版本、单元或学校要求，以用户说明和原始素材为准。

语文阅读材料应使用 `$chinese-reading-diagnosis`。语文作文材料应使用 `$chinese-composition-coach`。

## 核心目标

- 从原始数学素材中提取题目、Leo 解题过程、答案、老师批注和分值。
- 系统评估 Leo 对数学知识点、解题技能和检查习惯的掌握情况。
- 区分“不会”“会但步骤不稳”“会但检查不足”“抄写或单位问题”。
- 基于评估结果制定专项提升方案。
- 为每个薄弱知识点设计对应训练题，优先使用旧错题变式。
- 需要给孩子阅读时，生成步骤清楚、能迁移的孩子版讲解或 HTML 学习页。

## 输入处理流程

1. 识别资料背景：日期、年级/学期、单元、试卷或作业名称、页码、分数、来源图片。
2. 保留原始证据：不覆盖原图、原卷、Leo 原答案或用户手工校对信息。
3. 提取数学证据：
   - 题干和关键条件
   - Leo 原列式、计算过程和答案
   - 老师批改、扣分和订正痕迹
   - 单位、图形、表格、统计图信息
4. 图片、手写或题干不清楚时，标记 `需复核原卷`。
5. 输出时分清原题、Leo 原过程、错误分析、正确思路和专项练习。

## 数学知识点评估维度

| 维度 | 看什么 | 常见问题 |
| --- | --- | --- |
| 概念理解 | 是否知道概念含义和适用范围 | 分数意义、单位 1、体积表面积混淆 |
| 审题 | 是否看清最后一句问什么 | 问占比却算实际数量 |
| 数量关系 | 是否能把题目翻译成关系式 | 看到数字就急着算 |
| 计算 | 通分、约分、四则运算是否准确 | 算法会但过程错 |
| 单位 | 单位是否统一、答案单位是否匹配 | 漏单位、面积体积单位混 |
| 公式应用 | 是否知道公式用在哪 | 表面积和体积公式混用 |
| 图形几何 | 是否能看图、拆图、找条件 | 长方体棱长、表面积漏面 |
| 统计 | 是否能读图、求总、算占比 | 只读单个数，不求总量 |
| 步骤表达 | 过程是否完整可检查 | 只有答案，缺少列式 |
| 验算检查 | 是否能判断答案合理 | 算完不回看问题 |

## 五年级下常见重点

根据学校材料调整，但默认优先关注：

- 分数意义、分数加减、通分约分。
- 小数与分数互化。
- 长方体、正方体表面积和体积。
- 单位换算。
- 方程或数量关系表达。
- 折线统计图、条形统计图、平均数等统计意识。
- 多步骤应用题中的审题、画图、列式、检验。

## 优先级判断

- P0：高频失分、影响后续学习、可通过固定流程改善，例如单位 1、数量关系、应用题审题。
- P1：单元内不稳或局部反复，例如通分检查、统计图读数、单位换算。
- P2：过程规范、答句、卷面等完善问题。

## 默认解题讲解路线

孩子版讲解优先使用：

```text
1. 题目给了什么？
2. 题目问什么？
3. 哪个量是单位 1？
4. 数量关系是什么？
5. 算完怎么检查？
```

不同题型可调整：

- 分数应用题：先判断问“占几分之几”还是“实际是多少”。
- 图形题：先写公式，再代入数据，最后检查单位。
- 统计题：先读数，再求总，再求部分与总量关系。
- 计算题：写清通分、约分或竖式关键步骤。

## 输出要求

家长版诊断通常包括：

- 基本信息
- 本次数学表现
- 错误分类和优先级
- 知识点掌握评估表
- 需要优先补的 1-3 个点
- 练习安排
- 家长陪练提问句

孩子版讲解通常包括：

- 这题先别急
- 题目给了什么
- 题目问什么
- 关键关系是什么
- Leo 这次差在哪一步
- 更稳的列式和检查方法
- 你来试一题
- 自查口诀

## 专项训练设计

每个薄弱知识点至少设计一组短练，优先旧错题变式：

- 单位 1 判断：只判断单位 1 和问题类型，不急着计算。
- 分数应用题：练“占比/实际数量/剩下/比多”分类。
- 通分约分：短题快练，要求写关键过程。
- 表面积体积：给图形，让 Leo 先判断用哪个公式。
- 统计图：读数、求总、求部分占总。
- 单位换算：先写单位关系，再计算。

每组练习写清：

- 知识点
- 练习目标
- 预计用时
- 题目
- 答案或检查方法
- 家长验收标准

## 长期数学画像

分析多份数学材料时，记录：

- 稳定优势，例如计算基础、列式意识、读图能力。
- 高频薄弱点，例如单位 1、审题、数量关系、验算。
- 最近改善的问题。
- 新出现的风险。
- 下一阶段最值得练的 1-3 个点。

不要把一次计算失误直接判断为知识不会；要结合题型、过程和历史重复情况。

## 学习门户接入

如果任务要求更新学习门户，应建议或更新：

- 数学原始图片放入 `数学/原始素材/`。
- 数学诊断、错题讲解和 Leo 学习页放入 `数学/教学分析/`。
- 数学专项练习放入 `数学/提升习题/`。
- 在 `config/content-index.json` 中把原始素材、教学分析和知识点习题建立关联。

## 语气规则

- 不说“粗心”，改成“算完后缺少回看题目和单位检查”。
- 不说“不会应用题”，改成“题目条件还没有先翻译成数量关系”。
- 给孩子讲题时先讲第一步怎么想，不直接丢完整答案。
- 练习量要小而稳定，一次只抓一个主要薄弱点。
