# 语文阅读理解诊断与辅导

## 适用范围

当任务聚焦语文阅读理解、语文试卷阅读题、语文基础题中的阅读方法、信息提取、概括表达、句子还原、词语解释、中心理解或答题完整度时，使用本技能。

默认学习者为中国教育体系小学五年级下学期。若用户提供新的年级、学期、教材版本或学校单元，以用户说明和原始素材为准。

本技能不负责作文系统性修改；作文写作与作文素材分析应使用 `$chinese-composition-coach`。数学材料应使用 `$math-homework-diagnosis`。

## 核心目标

- 从原始素材中提取阅读题、Leo 答案、老师批注、扣分点和分值信息。
- 系统评估 Leo 在语文阅读知识点和答题方法上的掌握情况。
- 形成可追踪的评估记录，说明证据来自哪份试卷、哪道题或哪段原文。
- 基于评估结果制定专项提升方案。
- 为每个需要加强的知识点设计对应习题，优先使用旧错题变式。
- 需要给孩子阅读时，生成清楚、短小、温和的孩子版讲解或 HTML 学习页。

## 输入处理流程

1. 识别资料背景：日期、年级/学期、单元、试卷或作业名称、分数、页码、来源图片或 Markdown。
2. 保留原始证据：不覆盖原图、原卷、Leo 原答案或用户手工校对文本。
3. 提取阅读题证据：
   - 题干问法
   - 原文对应段落或关键句
   - Leo 原答案
   - 老师批注、扣分和得分情况
   - 题目分值和答题空间
4. 标记不确定内容：图片不清楚、手写难辨或原文缺失时写 `需复核原卷`。
5. 输出时分清原始内容、分析判断、优化答法和专项练习。

## 阅读知识点评估维度

按以下维度评估，不需要每次都全部展开，但要覆盖与错题相关的重点：

| 维度 | 看什么 | 常见表现 |
| --- | --- | --- |
| 审题 | 是否看清问法、关键词和分值 | 答非所问，只写感受 |
| 信息定位 | 是否能回原文找依据 | 凭印象答题，找不到关键句 |
| 概括能力 | 是否能删例子、留类别 | 抄原句多，概括词不准 |
| 词语语境义 | 是否能结合上下文解释 | 只写本义，不写文中意思 |
| 句子理解 | 是否能理解指代、衔接、作用 | 句子还原、作用题失分 |
| 中心理解 | 是否能把内容和主题连起来 | 知道大意但不会升到中心 |
| 人物品质 | 是否能用准确词概括人物 | 只写“好”“厉害” |
| 修辞效果 | 是否能说清修辞写出了什么 | 只写用了比喻，没有效果 |
| 分点表达 | 是否按分值写够点 | 3 分题只写 1 点 |
| 完整句表达 | 答案是否完整、通顺 | 关键词零散，缺少主语或原因 |

## 优先级判断

- P0：反复失分、影响大、可用固定流程明显改善的问题，例如信息定位、审题、分点表达。
- P1：某类题型反复不稳，例如句子还原、词语语境义、概括几个方面。
- P2：表达润色问题，例如答案句式不够自然、用词可更准确。

## 默认方法：阅读三问法

对孩子版讲解和训练，优先使用：

```text
1. 这道题问你什么？
2. 原文哪一句能支持你的答案？
3. 这是几分题，应该写几点？
```

常见题型处理：

- “为什么”：写清原因，必要时加结果。
- “体现了什么”：先写特点，再补原文证据。
- “哪几个方面”：按题干要求分条，每个方面单独写。
- “词语意思”：先写本义，再写文中具体意思。
- “句子还原”：看前后句的话题、指代词、承接词和转折词。
- “修辞作用”：写出修辞类型、描写对象、表达效果。

## 输出要求

家长版诊断通常包括：

- 基本信息
- 本次阅读题整体表现
- 按优先级列出的错误类型
- 知识点掌握评估表
- 需要优先加强的 1-3 个点
- 7 天或 3 次练习安排
- 家长陪练提问句

孩子版讲解通常包括：

- 这题先别急
- 第 1 步：题目问什么
- 第 2 步：原文证据在哪里
- 第 3 步：几分题，写几点
- Leo 这次差在哪一步
- 更稳的答题框架
- 你来试一题
- 自查口诀

## 专项习题设计

每个薄弱知识点至少给出一组短练，优先从旧错题变式：

- 信息定位：给题干，让 Leo 圈关键词并找原文句。
- 分点表达：给 2 分、3 分、4 分题，让 Leo 判断应写几点。
- 概括能力：给 3-4 个原文例子，让 Leo 提炼类别词。
- 词语语境义：写“本义 + 文中意思 + 为什么”。
- 句子还原：给前后句，说明放置理由。

每组练习写清：

- 练什么知识点
- 为什么要练
- 预计用时
- 验收标准
- 家长如何检查

## 学习门户接入

如果任务要求更新学习门户，应建议或更新：

- 原始素材放入对应科目的 `原始素材/` 或历史专题目录。
- 阅读诊断、三问法训练单、孩子版讲解放入 `语文/教学分析/`。
- 阅读专项练习放入 `语文/提升习题/`。
- 在 `config/content-index.json` 中把原始素材、分析文件和知识点练习建立关联。

## 语气规则

- 不说“你太粗心”，改成“答题前少了一步回原文找依据”。
- 不说“阅读能力差”，改成“信息定位和分点表达还没有形成固定流程”。
- 给孩子看的内容要短，先教方法，再给答案。
- 不为了完整而堆太多题，一次优先解决 1-2 个最影响得分的问题。
