# 英文作业与试卷诊断辅导

## 适用范围

当任务聚焦英文试卷、日常作业、单词听写、句型、语法、阅读、写作、错题或老师反馈时，使用本技能。

默认学习者为中国教育体系小学五年级下学期。若用户提供教材版本、单元词汇、学校要求或新的年级学期，以用户说明和原始素材为准。

## 核心流程

1. 识别日期、年级学期、教材版本、单元、素材类型、分数和来源文件。
2. 保留原图、Leo 原答案和老师批改，不直接覆盖原始内容。
3. 提取题干、题型、Leo 答案、正确答案、批改结果、分值和证据位置。
4. 图片或手写内容不清楚时标记 `需复核原卷`。
5. 区分知识点缺口、技能缺口、习惯问题和材料难度。
6. 把每个薄弱点连接到具体题号、原答案和批改证据。
7. 按 P0、P1、P2 排序，并生成短小、符合当前学段的专项训练。

## 评估维度

| 维度 | 重点检查 |
| --- | --- |
| 词汇 | 是否理解教材核心词汇和常见搭配 |
| 拼写 | 字母顺序、漏字母、近形词和大小写 |
| 句型 | 语序、问答对应和固定表达 |
| 时态 | 一般现在时、现在进行时等当前教材要求 |
| 动词形式 | 第三人称单数、助动词后的原形 |
| 名词形式 | 可数名词单复数和数量词对应 |
| 阅读 | 根据题干关键词定位原文信息 |
| 听力 | 音形对应、关键词识别和信息记录 |
| 写作 | 句子完整、语序、大小写、标点和连贯表达 |

## 孩子版讲解

每个错题优先讲清：

- 题目要你找什么或写什么。
- 句子里的关键词是什么。
- Leo 这次选错、写错或漏掉了什么。
- 可以套用的句型或检查方法。
- 一个替换词或替换句小练习。
- 一句自查提示。

讲解以当前教材词汇和短句为主，不使用明显超出五年级范围的语法术语。

## 专项训练

- 单词拼写：旧错词加相近词，控制在 8-12 个。
- 句型替换：保持句型，只替换人物、地点、时间或动作。
- 三单与原形：先圈主语，再判断动词形式。
- 名词单复数：先找数量词，再检查名词结尾。
- 阅读定位：圈题干关键词，回原文找同义表达。
- 写作修改：一次只改 3-5 句，检查语序、大小写和标点。

每组训练写清目标、预计用时、过关标准和家长检查方法。第一轮用于诊断，第二轮必须根据第一轮错因更换语境，不得简单重复题目。

## 输出与门户接入

- 原始图片保存到 `英文/原始素材/`。
- 诊断、错题讲解和 Leo 学习页保存到 `英文/教学分析/`。
- 专项练习保存到 `英文/提升习题/`。
- 所有结论保留证据链接，并在需要时更新学习门户和知识画像。

## 语气规则

- 不说“英语差”，改成具体可观察的问题。
- 不把一次拼写错误直接判断为词汇不会。
- 先肯定已经掌握的词汇或句型，再指出最值得练的一个点。
- 给 Leo 的内容使用短句、明确示例和轻量练习。
