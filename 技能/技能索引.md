# Leo 学习项目技能索引

这个目录用于保存 Leo 学习项目中可复用的本地技能。后续新增技能时，建议每个技能独立放在一个文件夹中，并保留 `SKILL.md` 作为入口说明。

## 已收录技能

| 技能 | 入口文件 | 主要用途 |
| --- | --- | --- |
| student-homework-diagnosis | [[student-homework-diagnosis/SKILL.md]] | 通用入口，用于跨学科资料、混合材料和总体学习画像；明确学科时优先分流到细分技能 |
| chinese-reading-diagnosis | [[chinese-reading-diagnosis/SKILL.md]] | 专门分析语文阅读理解、阅读试卷和阅读错题，评估阅读知识点并生成三问法训练与专项习题 |
| chinese-composition-coach | [[chinese-composition-coach/SKILL.md]] | 专门分析语文作文原图、转写稿、批改稿和作文素材，评估写作能力并生成作文修改与专项训练 |
| math-homework-diagnosis | [[math-homework-diagnosis/SKILL.md]] | 专门分析数学作业、试卷和错题，评估数学知识点并生成孩子讲解与专项训练 |
| english-homework-diagnosis | [[english-homework-diagnosis/SKILL.md]] | 专门分析英文作业、试卷、听写、阅读和写作，评估词汇语法与表达能力并生成专项训练 |

## 使用说明

- 项目内技能保存位置：`/Users/ben/Desktop/leo-notebook/技能`
- 当前 Codex 可直接调用的全局技能入口保存在：`/Users/ben/.codex/skills`
- 本项目技能应通过全局软链接接入，不要复制成多份真实目录。
